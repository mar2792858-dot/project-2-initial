* Learning Experience: What did you learn about inheritance AND AI-assisted development?
    - I learned a lot about inheritance before starting the project by diving in a little deeper asking AI, the best analogy that was used to help me really understand the difference between Interfaces and Abstract classes was you can have an abstract class such as Animal, an interface such as Flying and then two different classes such as Bird and Helicopter. The bird is going to extend Animal and implement Flying, but the helicopter is only going to implement Flying. I understand how this is very useful in keeping characteristics separate but usable by different types of classes. My first thought was creating a video game.
